# Uso de estas skills

Antes de trabajar en el área correspondiente, lee el `SKILL.md` indicado:

- Go y DLL Excel: `skills/go-feature-architecture/SKILL.md`.
- Diagramas de flujo Go: `skills/diagramas-flujo-go-roque/SKILL.md` cuando el usuario los pida o al terminar una funcionalidad Go con un flujo que valga la pena explicar.
- Backend Node.js nuevo: usa como referencia `https://github.com/Jonathan03R/Roque-stack` y lee `skills/apis-roque/SKILL.md` para diseñar endpoints y contratos. Revisa el código actual de Roque-stack antes de definir estructura o generar el backend.
- Cualquier código backend Node.js (rutas, controllers, schemas, services, middlewares, errores): `skills/apis-roque/SKILL.md`.
- Estructura y creación de módulos REST Node.js/TypeScript: `skills/estructura-backend-roque/SKILL.md`; registra funciones compartidas en `docs/REUTILIZABLES.md` del backend cuando corresponda.
- Tablas, SQL, RLS y esquemas Supabase: `skills/esquema-roque/SKILL.md`.
- npm: busca `npm-roque` entre las skills instaladas. No está incluida en este repositorio porque no fue encontrada durante su creación; no afirmes que existe ni inventes sus reglas.

Si una tarea cruza varias áreas, lee las skills correspondientes a cada una.
